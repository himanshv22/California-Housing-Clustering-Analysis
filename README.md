# California Housing Clustering Analysis

This project applies K-Means clustering on California housing data using latitude and longitude features.

## Technologies Used:
-Python
-Pandas
-NumPy
-Matplotlib
-Seaborn
-Scikit-learn
## Features:
-Data preprocessing
-Train-test split
-Feature normalization
-K-Means clustering
-Silhouette score evaluation
-Data visualization

Successfully grouped housing regions into clusters and visualized them using scatter plots.
